About Linear

Linear is built for high-performance software teams. We obsess over craft, speed, and keyboard-first developer workflows. Our web application is renowned for its instant responsiveness, offline capabilities, and design excellence.

About the Role

As a Staff Frontend Engineer, you will set the technical direction for our web clients and design systems. You will work across the stack with React, TypeScript, Next.js, and WebSockets to build lightning-fast collaborative experiences.

Responsibilities

  • Architect high-throughput, low-latency React and Next.js interfaces that feel instant to developers.
  • Collaborate with product and design to build accessible, WCAG AA compliant design systems in Tailwind CSS.
  • Lead technical design reviews for complex client-side synchronization and state management.
  • Optimize Web Vitals, memory consumption, and 60fps animations.
  • Mentor senior software engineers and champion software craftsmanship.

Requirements

  • 6+ years of production experience in React, TypeScript, and modern JavaScript.
  • Deep familiarity with Next.js App Router, React Server Components, and client performance profiling.
  • Hands-on experience with GraphQL, REST APIs, and real-time WebSockets.
  • Knowledge of cloud deployment pipelines, Docker, CI/CD, and GitHub Actions.
  • Strong grasp of System Design, Unit Testing (Jest, Vitest), and web security best practices.
